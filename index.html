코드 생성

FE_ 규칙과 컬러 파일명 suffix 규칙을 반영합니다.

제품코드: 자유형이면 FE_를 앞에 붙이고, 제품 본체 코드는 컬러 옵션을 제외한 기본 코드로 생성합니다.
썸네일: 제품코드_T_ALL / 제품코드_T_BK
캐러셀: 제품코드_C_BK_01 형식으로 생성합니다.

생성 결과

컬러는 파일명 suffix로 분리해서 생성합니다.
